# Customized Authentication Page Package

Generated by **Auth Page Builder**.

## Quick Start
```bash
npm install
npm start
```
Open the URL output by the server (default `http://localhost:3000/`) in your browser to view your standalone authentication page.

## Package Structure
```text
auth-page-package/
├── index.html                # Entry authentication HTML page
├── server.js                 # Standalone static web server
├── package.json              # Node.js dependencies and start script
├── README.md                 # Package documentation
├── config/
│   └── auth-config.json      # Complete configuration single source of truth
├── css/
│   └── styles.css            # Complete standalone CSS styling
├── js/
│   ├── config.js             # Client configuration loader
│   ├── app.js                # Runtime application logic & navigation
│   ├── redirectService.js    # Post-authentication redirect handler
│   └── integration.js        # Landing page integration helper
└── assets/                   # Backgrounds, logos, and icon assets
```
