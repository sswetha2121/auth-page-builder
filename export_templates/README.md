## Backend Quick Start
```bash
cd backend
python -m venv venv

# Windows Activation:
venv\Scripts\activate

# Install Dependencies & Migrate
pip install -r requirements.txt
python manage.py migrate

# Start Django Backend Server
python manage.py runserver 8000
```

## Frontend Setup
Serve `frontend/index.html` via any static HTTP server (e.g. `npx serve frontend` or python `http.server`).
The frontend will connect to `http://localhost:8000/api` configured in `config/auth-config.json`.
